---

## 🚀 How to Run

### 1. Run Frontend Web App
```bash
cd frontend
npm install
npm run dev
```
Runs on **http://localhost:3000**.

### 2. Run Backend Express API
```bash
cd backend
npm install
npm run dev
```
Runs on **http://localhost:5000**.
